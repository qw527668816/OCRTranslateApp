# 群晖自建「口袋智能体」网页版(局域网 5 分钟)

> 目标:让网页版跑在你自己的群晖上,家庭 WiFi 里随时秒开,不依赖任何外部网站。
> 文件:工作区根目录的 `口袋智能体.html`(和 App 内置的是同一份)。

---

## 方案 A:局域网使用(推荐,最简单最安全)

### 步骤

1. **群晖安装 Web Station**:套件中心 → 搜索「Web Station」→ 安装并打开(按向导完成,默认设置即可)。
2. **上传页面**:File Station → 进入 `web` 共享文件夹(DSM7 如果没有 web 文件夹,Web Station 首次启动会创建)→ 上传 `口袋智能体.html` → **重命名为 `index.html`**。
3. **手机访问**:同一 WiFi 下,Safari 打开 `http://群晖局域网IP`(比如 `http://192.168.1.10`;IP 在 DSM 控制面板 → 信息中心 看)。
4. 看到「口袋智能体」页面 → 分享 → **添加到主屏幕** → 完成,以后点图标即开。
5. 进设置页填 API Key → 测试连接 → 四个功能随便用。

### 为什么推荐局域网方案

- 页面是纯静态的,群晖只负责"递文件",几乎零负载
- API Key 的请求从手机**直连服务商**,不经过群晖,也不经过任何第三方
- 不暴露公网,无安全顾虑
- 如果 Web Station 用了非 80 端口,地址写成 `http://群晖IP:端口`

---

## 方案 B:外网访问(进阶,可选)

家庭外(流量)访问有两条路,按需选:

1. **QuickConnect 不适用于网页目录**(它只代理 DSM 本身),所以要么:
2. **DDNS + 端口转发**:
   - 控制面板 → 外部访问 → DDNS 启用(群晖免费域名 `xxx.synology.me` 或你自己的域名)
   - 路由器把外部端口(建议非标,如 8443)转发到群晖的 Web Station 端口
   - 控制面板 → 登录门户 → 高级 → 反向代理,给 Web Station 挂上 Let's Encrypt 证书
3. ⚠️ **安全提醒**:外网暴露网页目录务必配 HTTPS(证书),否则你在页面里填的 API Key 有被窃听风险;家里宽带 80/443 常被运营商封,用非标端口。**拿不准就只用方案 A**,外出场景交给线上链接或 App 内置页。

---

## 三条使用路线的分工(最终形态)

| 场景 | 用哪个 | 依赖 |
|---|---|---|
| 在家 / 同一 WiFi | 群晖自建版(主屏幕图标) | 你的 NAS 在线 |
| 外出 / 临时 | 线上链接 pocket-agent-3g8t.zai-ai.site 或签名 App | 网络 |
| 完全离线 | **签名 App 的「口袋」标签页**(页面内置在 App 里) | 无(调 API 才联网) |

> 签名 App(ipa)构建:见《自用安装指南.md》——fork → GitHub Actions 出 ipa → ESign 签名。App 里第四个标签「口袋」就是这份网页,断网也能打开界面。
