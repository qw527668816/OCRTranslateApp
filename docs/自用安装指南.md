# 自用安装指南(非越狱 / 非巨魔 iPhone 可用)

> 本仓库在 [OCRTranslateApp](https://github.com/limaoswag-wq/OCRTranslateApp) 基础上改造:
> ①逐段**原文-译文对照**;②新增**截图翻译**(相册/拍照);③新增**智能体**对话页(技能预设);④云端 API 为主、**本地 AI 留接口**;⑤App Group **一处常量**管理,适配 ESign/轻松签等自签工具,普通手机无需巨魔/越狱。
>
> 🆓 **免证书、任意 iPhone 可用的快捷指令版**(对标 TrollAgent 功能,本文件是签名 App 线,两线分开维护):见《[免证书快捷指令版.md](免证书快捷指令版.md)》

## 0. 三个功能怎么用

| Tab | 功能 | 依赖 |
|---|---|---|
| 屏幕翻译 | 开关式实时翻译:点「开始屏幕翻译」→ 选 ScreenTranslator → 任意 App 内自动逐段翻译 | 录屏扩展 + App Group 正常 |
| 截图翻译 | 相册选图/拍照 → 系统 OCR → 逐段对照翻译,可复制 | 只需 API,**不依赖 App Group** |
| 智能体 | 技能预设(翻译官/总结/报错解释…)对话,支持导入截图 OCR 后提问 | 同一个 AI 接口,**不依赖 App Group** |
| 口袋 | 内置网页版「口袋智能体」:问答/对话/翻译/识图,页面打包在 App 内,不依赖任何网站 | 各自的 API 配置 |

> 即使你的签名证书不支持 App Group(只有实时屏幕翻译失效),**截图翻译和智能体仍然完全可用**。

对照开关:设置 → 语言设置 → 「原文-译文对照」。

## 2. 把代码变成「你的仓库」

1. 登录 GitHub,Fork 本仓库(或下载 zip 后在 GitHub 网页「Upload files」新建自己的仓库)。
2. 之后的每一次 push 都会自动触发打包,也可在 Actions 页手动 **Run workflow**。

## 3. 【关键一步】按你的证书改 App Group / Bundle ID

**为什么要改**:实时屏幕翻译的结果靠 App Group 在录屏扩展和主 App 之间传递。原项目把组名硬编码在 4 处,现已收敛为 1 处常量 + 2 个签名文件。ESign 重签时,签名配置里的 App Group 必须和代码里完全一致。

### 3.1 只改组名(推荐先做)

需要改的 3 个文件:

| 文件 | 位置 | 改什么 |
|---|---|---|
| `Shared/AppConfig.swift` | 第 11 行 `appGroupID` | 改成你证书支持的组名 |
| `OCRTranslate/OCRTranslate.entitlements` | 第 7 行 | 同步改 |
| `ScreenTranslator/ScreenTranslator.entitlements` | 第 7 行 | 同步改 |

Git Bash 一键替换(在仓库根目录执行):

```bash
OLD="group.com.limaoswag.ocrtranslate"
NEW="group.改成你的组名"
grep -rl "$OLD" --include="*.swift" --include="*.entitlements" . | xargs sed -i "s/$OLD/$NEW/g"
grep -rn "group\." Shared/AppConfig.swift *.entitlements */*.entitlements   # 确认 3 处都已替换
```

### 3.2 若证书还限定了 Bundle ID

需要改 4 处(保持扩展 ID = 主 ID + 后缀):

- `Shared/AppConfig.swift`:`mainBundleID`、`extensionBundleID`
- `project.yml`:两个 `PRODUCT_BUNDLE_IDENTIFIER`
- `ContentView.swift` 里的广播入口已引用 `AppConfig.extensionBundleID`,不用单独改

### 3.3 ESign 侧

签名前在 ESign 的证书/签名设置里,确认 App Group 勾选了**与代码相同的组名**(有些证书自带固定组名,那就把代码改成它的)。

## 4. GitHub Actions 云端打包(全程无需 Mac)

1. push 到 main(或手动 Run workflow)→ Actions 页出现「Build IPA」。
2. 构建约 10~20 分钟,完成后在该次运行底部 **Artifacts** 下载 `OCRTranslate-IPA`,解压得到 `OCRTranslate.ipa`。
3. 产物是**未签名(仅 ldid 伪签)的 ipa** —— 这正是 ESign 重签需要的输入格式。
4. 费用:公开仓库 macOS runner 免费;私有仓库按 10 倍时长计费(有每月免费额度),**建议公开仓库**(代码里不含任何密钥,密钥只存在你手机的设置里)。

---

## 5. ESign 签名安装

1. ESign 导入 `OCRTranslate.ipa` → 选择你的证书。
2. 确认签名详情:App Group 与第 3 步一致;包含 `PlugIns/ScreenTranslator.appex`(录屏扩展)。
3. 签名 → 安装 → (新证书)设置 → 通用 → VPN与设备管理 里信任企业证书。
4. 首次使用「屏幕翻译」时,系统会请求屏幕广播权限,允许即可。
5. 证书有效期到期(7 天/1 年,看你的证书类型)后重新签名安装,数据不受影响。

## 6. 配置 API

### 6.1 AI 翻译(推荐主力,智能体共用)

App 内:设置 → 翻译引擎 → **AI 翻译(OpenAI 兼容)**:

| 字段 | 示例(DeepSeek) | 说明 |
|---|---|---|
| API 地址 | `https://api.deepseek.com` | 填主域名即可,App 自动补全 `/v1/chat/completions`;也兼容已带 `/v1` 或完整路径的填法 |
| API Key | `sk-…` | |
| 模型名称 | `deepseek-chat` | 通义 `qwen-plus` / Kimi `moonshot-v1-8k` / 千帆见其文档 |
| Prompt | 默认即可 | 默认提示词要求模型按 JSON 键值逐段回填,保证"第几段原文配第几段译文"不串行 |

其他 OpenAI 兼容端点同理(百度千帆 v2 接口 `https://qianfan.baidubce.com/v2`、Groq、OpenAI 等)。

### 6.2 百度翻译(传统引擎,备用)

[fanyi-api.baidu.com](https://fanyi-api.baidu.com) 注册实名 → 「翻译API」创建应用(通用翻译)→ 设置里填 AppID + 密钥。免费版 QPS=1;本 App 会把整屏段落合并为一次请求,不放大限流。

## 7. 常见问题排查

| 现象 | 原因 / 处理 |
|---|---|
| 实时翻译一直不更新 | App Group 三处不一致(§3.1)或 ESign 签名没勾组名;截图翻译/智能体不受此影响 |
| 「开始直播」列表里找不到 ScreenTranslator | 扩展签名失败或扩展 Bundle ID 不是主 ID 的子前缀(§3.2) |
| 百度报 54001 | AppID/密钥错误;54003 = QPS 限流,等 1 秒重试 |
| AI 报 401 | Key 错误;404 = 地址填错,对照 §6.1 的三种填法 |
| 译文串行/错位 | 模型没按 JSON 返回(极少数情况),App 会兜底显示为整段译文,可换强一点的模型 |
| Apple 引擎报"翻译会话未就绪" | 语言包尚未下载完成:系统会弹窗,允许并等下载完成后重试 |
| Apple 引擎在实时屏幕翻译提示"暂不支持" | 属预期:录屏扩展内无法使用设备端会话,实时翻译请用 AI/百度引擎 |
| 对照显示想关掉 | 设置 → 语言设置 → 关闭「原文-译文对照」 |

## 8. 免费离线:Apple 设备端翻译(已实装)+ 快捷指令 + 本地 AI 预留

### 8.1 Apple 设备端翻译(推荐默认引擎,零费用)

这就是同类商业 App("屏幕翻译"那类)的核心原理:

- 设置 → 翻译引擎 → **Apple 翻译(设备端免费离线)**:无需 API Key、不联网、零费用
- 要求 **iOS 18+**;首次使用系统会提示下载"英中翻译资源"(即其他 App 里那个「Apple 英中翻译资源」)
- 实现:`OCRTranslate/App/AppleTranslationService.swift` + 根视图隐藏桥接 `TranslationBridgeView`(Translation 框架的 session 只能经 SwiftUI `.translationTask` 获取)
- 限制:实时屏幕翻译(录屏扩展)内不可用(扩展无 UI 拿不到会话,已做降级提示);**截图翻译 / 智能体 / 快捷指令动作均可**;iOS 18 以下自动提示切换引擎

### 8.2 快捷指令动作(新增)

快捷指令 App → 搜索「**翻译剪贴板**」→ 可绑定:操作按钮 / 轻点背面 / 锁屏控件 / Siri。复制任意文字 → 触发 → 弹出逐段对照翻译,使用 App 内当前引擎。

### 8.3 本地大模型(接口预留,待定)

- 对接点:`Shared/LLMClient.swift` 的 `ChatBackend` 协议(`LocalAIBackend` 为预留桩)
- 未来接设备端 Apple 智能(国行 iOS 27.3+)、MLX、llama.cpp:实现该协议即可,**上层翻译、对照、智能体一行不用改**
