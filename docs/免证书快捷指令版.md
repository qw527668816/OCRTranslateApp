> 对标 TrollAgent/TrollOpen 的功能,把**不需要巨魔特权**的部分全部用 iOS 自带「快捷指令」实现。
> 无需任何证书、无需安装任何 App、无需电脑;系统 iOS 15 起可用,推荐 iOS 16+。
> 这份是**免证书通用版**;**签名 App 版**(实时屏幕翻译/悬浮/智能体完整界面)见《自用安装指南.md》,两条线分开维护。

## 1. 准备(10 分钟)

1. **申请一个 API Key**(四选一,和 TrollAgent 同款预设):
   - 硅基流动 siliconflow.cn(有免费模型,推荐起步)
   - 阿里百炼 bailian.aliyun.com(`qwen-vl-ocr` / Qwen 系列)
   - DeepSeek 平台(api.deepseek.com)
   - Google Gemini API(aistudio.google.com,有免费额度;国内网络需自理)
2. iPhone **设置 → 辅助功能 → 触控 → 轻点背面**:选一个快捷指令(触发器,后面配好再回来选)
3. (iPhone 15 Pro+)操作按钮、控制中心也可绑快捷指令

> 通用要点:所有指令里调 API 都用「**获取 URL 内容**」动作:方法 POST、头部加 `Authorization: Bearer sk-你的Key`、请求体选 JSON。API 地址填到 `/v1/chat/completions` 为止。

## 2. 指令一:快捷问答(对应 TrollAgent 指令 12)

**触发**:轻点背面 / 操作按钮 / Siri"快捷问答"

动作链(逐条添加):
1. 「**要求输入**」:提示"问点什么"(键盘弹出)
2. 「**文本**」:内容为
   ```
   作为 AI 助手,请提供准确、有帮助的回答。

   用户的问题:〔步骤1 的输入〕
   ```
3. 「**获取 URL 内容**」:
   - URL:`https://api.siliconflow.cn/v1/chat/completions`
   - 方法:POST;头部:`Authorization` = `Bearer sk-你的Key`
   - 请求体(JSON):
   ```json
   {"model":"Qwen/Qwen2.5-7B-Instruct","messages":[{"role":"system","content":"作为AI助手,请提供准确、有帮助的回答"},{"role":"user","content":"替换为步骤2的文本"}],"stream":false}
   ```
4. 「**获取词典值**」:获取 `choices` → 获取第 1 项 → `message` → `content`
5. 「**显示结果**」;可再加「**拷贝到剪贴板**」

> 换模型只改 `model` 字段:DeepSeek 填 `deepseek-chat`(地址换 api.deepseek.com/v1/chat/completions);Gemini 走 OpenAI 兼容地址 `https://generativelanguage.googleapis.com/v1beta/openai/chat/completions`。

## 3. 指令二:智能对话(多轮,对应指令 13)

在指令一基础上,用「**重复**」(无限)包住 1~5 步,并在第 2 步文本里拼接历史:

```
作为 AI 助手,请提供准确、有帮助的回答。

对话历史:
〔变量:历史〕

用户新问题:〔步骤1 的输入〕
```

每次回答后:「**文本**」= 历史旧值 + `\n用户:` + 输入 + `\n助手:` + 回答 → 更新「历史」变量;再放一个「**从菜单中选择**」(继续 / 结束)决定是否跳出循环。

## 4. 指令三:截图翻译(双语对照,核心指令)

**触发**(三选一):
- A. 截屏后点左下角缩略图 → 分享 → 运行本指令(指令开启"接收图像和媒体文件,在共享面板显示")
- B. 辅助触控/轻点背面绑「截屏」动作的版本(指令内自己截屏)
- C. 相册选图:「选择照片」动作

动作链(以 A 为准):
1. 接收图像(共享面板)
2. 「**从图像提取文本**」(系统 Live Text OCR,免费离线)
3. 「**文本**」= 翻译提示词:
   ```
   你是专业翻译。下面的文本来自屏幕截图,按行逐段翻译为简体中文。
   输出格式:每段先输出原文,换行输出译文,两段之间空一行。不要解释。
   〔步骤2 的识别文本〕
   ```
4. 「获取 URL 内容」POST 到你的 LLM(同指令一)
5. 取 `choices.1.message.content`
6. 「**显示结果**」+「**拷贝到剪贴板**」(可选「**快速查看**」看大图式长文)

> **纯系统零 API 版**(LLM 也不想要):把第 3~5 步换成「**翻译文本**」动作(苹果自带,离线),但没有对照格式。iOS 27.3 国行正式版后,可换「**使用模型 → 端侧**」动作,免费离线 + 大模型质量。

## 5. 指令四:截图问 AI(对应 VLM,两条路线)

### 路线 A:VLM 直读图(效果最好,对应 TrollAgent 的 VLM 槽位)
1. 接收图像(共享面板)
2. 「**Base64 编码**」编码该图像
3. 「**文本**」拼出 data URL:`data:image/jpeg;base64,〔Base64 结果〕`
4. 「获取 URL 内容」POST:
   ```json
   {"model":"Qwen/Qwen2.5-VL-32B-Instruct","messages":[{"role":"user","content":[{"type":"text","text":"看这张截图,用中文回答:里面是什么/有什么文字/我可能想问什么"},{"type":"image_url","image_url":{"url":"替换为步骤3的文本"}}]}],"stream":false}
   ```
   (硅基流动/阿里百炼/Gemini 均兼容此格式;OCR 专用可换阿里百炼 `qwen-vl-ocr` 模型)
5. 取 `choices.1.message.content` → 显示

### 路线 B:OCR + LLM 代替 VLM(省钱,对应 TrollAgent 那个开关)
= 指令三的 OCR 之后,把翻译提示词换成"解释/分析这段文字:…"即可,其余完全一致。

## 6. 指令五:剪贴板翻译(轻点背面即翻)

1. 「**获取剪贴板**」
2. 后续同指令三第 3~6 步(提示词不变,输入换成剪贴板变量)

## 7. (选做)指令六:AI 生图

「要求输入」描述 → 「获取 URL 内容」POST 硅基流动 `https://api.siliconflow.cn/v1/images/generations`,JSON `{"model":"Kwai-Kolors/Kolors","prompt":"输入"}` → 取 `data.1.url` → 「获取 URL 内容」GET 下载 → 「存储到相册」。

## 8. 已取消的巨魔专属功能与替代

| 取消项 | 系统限制原因 | 替代 |
|---|---|---|
| 区域截图 / 无声录屏 / 长截图 | 需 root 特权 | 系统自带截屏/录屏(带红条);长截图用 Safari 自带整页截图 |
| 悬浮球 / 边缘扇形菜单 / 全局双击 | 无全局悬浮窗权限 | 轻点背面 + 操作按钮 + 辅助触控 + 控制中心 |
| 灵动岛接入 | 需 Live Activity 常驻(需签名 App) | 锁屏通知 |
| 全屏原位替换翻译(钉图) | 悬浮展示需巨魔;API 本身可用 | 签名 App 版计划接入百度图片翻译 API(见《自用安装指南.md》) |
